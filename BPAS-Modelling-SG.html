Business Process Modelling 🧭

IS210 BPAS · Week 2 Session Notes
One question it answers How do we map a business process accurately from high-level context down to workflow steps?
🗺️ The 4 Layers of Process Modelling
1
Abstraction & Baseline
  • Abstraction Scope: Must be defined early. Don't discuss "continents" when stakeholders need "cities".
  • Process Discovery: Analyze the "as-is" current state before solving for the future state.
Without a baseline and clear metrics, an organization has no way to measure if a process change is actually an improvement.
Worked Example: Retail Complaints
Are we fixing global returns or one store's social media feedback? We must set the scope and record current wait times first.
2
Org & Location Models
  • Job (Title): The formal position title.
  • Role (Function): The specific responsibilities within a process. A single job usually holds multiple roles.
  • Location: Defines where the process happens. Dictates physical constraints (Taxes, Time zones, Data laws).
Worked Example: Retail Complaints
Job: Sales Associate. Role: Complaint Handler.
Location: Singapore (Process must comply with PDPA).

4
Workflow Basics (BPMN)

Mapped via swimlanes (ownership) and flow elements:

✋
Manual Task: Human only (no IT system used).
👤
User Task: Human interacting with an IT system.
⚙️
Service Task: Automated system only (no human).
✖️
XOR Gateway: Exclusive decision (Splits to A or B).
➕
Parallel Gateway: Concurrent execution (A and B).
Worked Example: Retail Complaints
The Complaint Handler (Swimlane) logs the ticket (💻 User Task). The path splits: Refund OR Replace (✖️ XOR).
🩴 Chancleta Alerts (Fatal Errors)

1. Job vs Role Trap

Using formal titles instead of process functions in swimlanes.

Swimlane: "Store Manager" Swimlane: "Approver"

2. "We Use It" Trap

Thinking an app is internal just because your staff uses it for work.

WhatsApp is an Internal System WhatsApp is an External System

3. Manual System Trap

Thinking data entry is "Manual" because human hands do the typing.

Typing data is a Manual Task Typing data is a User Task
